# Template Source

Verified on 2026-05-03.

EMNLP 2026 main conference submissions go through ARR. The EMNLP 2026 call for main conference papers says long and short submissions should follow ARR submission requirements, including "Paper Submission and Templates".

ARR states that submissions must use the official ACL style template and links to the ACL style files repository:

- EMNLP 2026 main call: https://2026.emnlp.org/calls/main_conference_papers/
- ARR call for papers: https://aclrollingreview.org/cfp
- Official ACL style files: https://github.com/acl-org/acl-style-files
- Official zip URL used here: https://github.com/acl-org/acl-style-files/archive/refs/heads/master.zip
- ACLPUB formatting guide: https://acl-org.github.io/ACLPUB/formatting.html

Local files:

- `paper/submission/emnlp2026_acl_template/acl-style-files-master.zip` stores the downloaded official zip.
- `paper/submission/emnlp2026_acl_template/acl-style-files-master/` stores the extracted upstream template.
- `paper/submission/main.tex` is the ThinkStream working manuscript derived from `acl_latex.tex`.
- `paper/submission/acl.sty` and `paper/submission/acl_natbib.bst` are copied from the extracted official template for local compilation.

Decision:

Start and maintain the EMNLP paper directly from this official ACL template. Do not use third-party templates unless only for visual reference.
